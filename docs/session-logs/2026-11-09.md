## Fakta peta memori (dari /proc/149/maps, PID 149 = im.elf / ScalarDaemon)
- `0x82df9000` +0x7C000 (508KB) — **region parameter ISP** (bukan image plane;
  stabil; cuma 2 diff saat Contrast -3↔+3). SEBELUMNYA dikira image plane.
- `0x92ec0000` +0x12C000 (1.228.800 = 1280×960) — image plane liveview GANDA
  (pola berulang offset 0x96000). Churn besar (1223 runs) saat Contrast berubah
  = bukti piksel output berubah, tapi BUKAN lokasi LUT.
- `0xC0000000` +0x98000 (622KB) — work memory ISP (baris 425-entri val 0–24,
  bukan LUT). Di-map daemon di 0d45a000-0d4f0000.
- `0x82d90000` (16KB) — "IMCMN VER:109" + magic 55aa55aa + param table.
  IDENTIK antara -3/+3 → bukan lokasi kurva.
- `0x83438000` (32KB) — descriptor/log buffer, churn log saja.
- `0x8e6d1000`, `0x965de000`, `0x82eae000` — identik/statis.
- `0xf1000000` — **JANGAN DUMP.** Dua kali camera wedge/reboot persis saat
  memdump jendela ini (register hardware gated → kernel panic diduga).

## TEMUAN KUNCI: kandidat koefisien Contrast
- Diff valid -3 vs +3 di `0x82df9000`: hanya **2 diff**:
  - `0x5340C` (fisik `0x82E4C40C`): 2 byte, u16 `0x3CE5`(-3) → `0x3D05`(+3),
    delta +0x20. Value stabil cross-reboot di +3 (0x3D05 di p3_82df, v2_m3,
    v2_p3 — tiga dump berbeda waktu/reboot, semuanya +3).
  - `0x574F5`: 32 byte log text (MWF RsrcAcsr) — noise.
- Artinya: kemungkinan scalar/anchor parameter (diduga shoulder anchor di
  domain 14-bit: 0x3CE5≈95.2%, 0x3D05≈95.3%), BUKAN tabel kurva penuh.
- Protocol verifikasi A==C belum dijalankan (kamera wedge duluan).
